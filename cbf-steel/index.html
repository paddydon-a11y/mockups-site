Built from the footings up

A gate is only as good as what holds it. We dig, reinforce and set every post ourselves before a gate is hung.

1

Dig and reinforce

Each footing is dug out and laid with steel mesh before any concrete goes in.

2

Set the post

Posts are set plumb and braced so the gate hangs true.

3

Cast the pad

Concrete is poured and finished flat around the post.

4

Hang the gate

The gate goes on, aligned, tested and handed over.
