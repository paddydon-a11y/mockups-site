How an arch is rebuilt

The same bricks, back in the same place

Brick arches carry the load over a doorway or window. When they fail we do not patch them. Each brick is taken down, marked, cleaned and set back where it was laid originally.

1

Take down

The defective arch is removed and each brick marked and laid out in formation.

2

Clean off

Old mortar cleaned from every brick so it can be reused in its original position.

3

Rebuild

The arch is rebuilt on a former, brick shapes set to span the opening correctly.

4

Point in

Joints pointed in lime mortar, colour matched to the surrounding brickwork.
