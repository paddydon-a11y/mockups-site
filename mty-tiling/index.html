About MTY Tiling

MTY Tiling is run by Matty from Wigton, tiling homes and commercial premises across Cumbria. From a single kitchen splashback to a full wet room, every job is set out before the first tile goes on, so the cuts sit where you will not notice them and the joints run straight. You deal with Matty from the first visit to the final clean.
