About RSG Fabs

RSG Fabs Ltd is a steel fabrication company working from Unit 26 on Eastwood Trading Estate in Rotherham. Director Gary Edwards and the team design, fabricate, install and repair steelwork for contractors, developers, manufacturers and waste firms, and build turnkey skips and RoRo containers. The workshop is open Monday to Friday, 7am to 4pm.

SCCS Certified to UKCA Execution Class 3

RSG Fabs is certified by SCCS, a UKAS accredited certification body for structural steelwork, to BS EN 1090 Execution Class 3. Our factory production control is independently audited, so the structural steelwork we supply can carry the UKCA mark. Execution Class 3 covers more demanding structures than the Execution Class 2 used on most buildings.
